# 🪙 Projeto Conversor de Moedas

Um aplicativo web interativo e responsivo desenvolvido para realizar a **conversão de valores entre diferentes moedas** de forma rápida e intuitiva. 

Este projeto foi excelente para consolidar meus conhecimentos em manipulação de eventos no DOM (Document Object Model) e aplicação de lógica matemática utilizando JavaScript Puro.

---

## 🚀 Funcionalidades

- **Conversão Dinâmica:** Permite que o usuário insira um valor, selecione as moedas de origem e destino, e obtenha o resultado calculado imediatamente.
- **Interface Intuitiva e Limpa:** Design focado na experiência do usuário (UX), facilitando o entendimento e o uso do formulário.
- **Validação de Dados:** Sistema que garante que apenas números válidos sejam processados para o cálculo da conversão.

---

## 🛠️ Tecnologias Aplicadas

- **HTML5:** Estruturação semântica para criação do formulário, inputs de dados e elementos de seleção (`<select>`).
- **CSS3:** Estilização moderna, alinhamento de componentes e garantia de que o visual seja agradável e amigável.
- **JavaScript (Vanilla):** Responsável por capturar os valores digitados, executar os cálculos matemáticos de conversão e atualizar o resultado na tela dinamicamente.
- **Git & GitHub:** Ferramentas utilizadas para o controle de versão e documentação do portfólio.
